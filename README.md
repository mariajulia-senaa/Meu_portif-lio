## Sobre o projeto

Uma página única e responsiva, com layout em duas colunas:

- **Coluna esquerda:** foto, apresentação, idioma e barras de habilidades (C, Python, HTML, CSS e JavaScript).
- **Coluna direita:** metas no AI Lab (Cyber Security, Desenvolvimento Full-Stack e Banco de Dados), projetos recentes e links de contato.

O objetivo foi praticar a base do desenvolvimento web (estrutura, estilo e interatividade) construindo algo real e útil para a minha trajetória.

## Tecnologias utilizadas

- **HTML5**: estrutura semântica da página
- **CSS3**: estilização e layout
- **JavaScript**: interatividade
- **Google Fonts** (Poppins): tipografia
- **Font Awesome**: ícones

## Como executar localmente

Não é necessário instalar nada. Basta:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/mariajulia-senaa/Meu_portif-lio.git
   ```
2. Entrar na pasta:
   ```bash
   cd Meu_portif-lio
   ```
3. Abrir o arquivo `index.html` no navegador (clique duas vezes ou use a extensão Live Server do VS Code).
