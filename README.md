## Sobre o projeto

Uma página única, responsiva e com tema escuro em tons de roxo e destaque em verde-água. O layout é dividido em duas colunas:

**Coluna lateral (perfil)**
- Foto, nome e curso
- Apresentação e informações básicas
- Idioma
- Barras de habilidades: C, Python, HTML, CSS e JavaScript

**Coluna principal (conteúdo)**
- **Metas no AI Lab:** Cyber Security, Desenvolvimento Full-Stack e Banco de Dados
- **Projetos recentes:** com link direto para cada repositório
- **Contatos:** GitHub, LinkedIn e e-mail

## Tecnologias

## Como executar localmente

Não é preciso instalar nada.

```bash
# 1. Clone o repositório
git clone https://github.com/mariajulia-senaa/Meu_portif-lio.git

# 2. Entre na pasta
cd Meu_portif-lio
```

Depois, abra o `index.html` no navegador (duplo clique) ou use a extensão **Live Server** do VS Code.
